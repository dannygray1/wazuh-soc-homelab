# Security Monitoring and Investigation Screenshots

This directory contains screenshots documenting Windows security event collection, Wazuh alert analysis, and controlled failed-authentication testing within the SOC home lab.

The evidence includes Windows Event ID 4625, Wazuh Rule 60122, authentication failure details, and timestamp validation following correction of the Windows VM's time-zone configuration.

Additional screenshots document baseline endpoint monitoring, Windows service-change alerts, and security configuration assessment findings.

For the complete investigation, see [Failed-Logon Investigation](../../documentation/failed-logon-investigation.md).
