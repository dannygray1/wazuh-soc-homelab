# Windows 11 Wazuh Agent Deployment Screenshots

This directory contains screenshots documenting the installation, configuration, enrollment, and connectivity validation of the Wazuh 4.14.9 agent on a Windows 11 Enterprise Evaluation virtual machine.

Screenshots demonstrate the agent deployment configuration and successful communication between the Windows endpoint and the Wazuh manager.

For detailed deployment procedures and validation steps, see [Windows Agent Deployment](../../documentation/windows-agent-deployment.md).
